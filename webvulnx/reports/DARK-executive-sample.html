DARK-001 Critical

SQL Injection (Error-Based)

CVSS
9.8
CWE
CWE-89
OWASP
A03:2021 Injection
Parameter
id

URL https://shop.example.com/product?id=1

Impact

An attacker can read, modify or destroy the database, bypass authentication, and in many stacks escalate to remote code execution via stacked queries or INTO OUTFILE.

What the scanner observed

Error-based SQLi confirmed on the product identifier.

Evidence

MySQL: You have an error in your SQL syntax

Payload

1'

Remediation

Use parameterised queries / prepared statements on every SQL call. Never concatenate user input into SQL. Apply least-privilege DB accounts and disable stacked queries where the driver allows it.

References

  • https://owasp.org/www-community/attacks/SQL_Injection
